# حزمة مهارات Zoho Sprints MCP — عربي

هذه الحزمة تضبط طريقة تعامل مساعدات البرمجة والـ AI مع Zoho Sprints عبر MCP، وفق دورين منفصلين:

1. **Admin / مسؤول المشروع**: إدارة المشاريع والـ Sprints وعناصر العمل وفق الصلاحيات الفعلية المتاحة في Zoho.
2. **Developer / مطور نظم**: إنشاء ومتابعة عناصر العمل ضمن حدود التكليف والـ Sprint النشط، مع منع التكرار قدر الإمكان.

> **مهم:** هذه ملفات تعليمات وسياسات للمساعد، وليست نظام صلاحيات أمنيًا بحد ذاتها. الصلاحية النهائية يفرضها Zoho Sprints وحساب MCP المتصل. لا تضع كلمات مرور أو OAuth tokens داخل هذه الحزمة أو داخل Git.

## محتويات الحزمة

- `skills/zoho-sprints/SKILL.md`: المهارة الأساسية المحايدة بين المحررات.
- `policies/ROLE_POLICY_AR.md` و`policies/ROLE_POLICY_EN.md`: قواعد الدورين.
- `workflows/`: إجراءات الإنشاء والاستعراض وفحص التكرار.
- `prompts/`: أوامر جاهزة للاستخدام.
- `editor-guides/`: إرشادات دمج المهارة في أدوات مختلفة.
- `templates/`: إعداد الدور وبيانات المستخدم.
- `mcp-config/`: مثال عام فقط لتكوين MCP، يحتاج إلى اسم الأمر الحقيقي الذي توفره خادمتك.

## التثبيت السريع

1. فك الضغط داخل مستودع المشروع أو مجلد إعداداتك.
2. عيّن الدور في `templates/zoho-sprints-profile.example.yaml` إلى `admin` أو `developer`.
3. عيّن معرف مستخدم Zoho Sprints الصحيح في ملف إعداد محلي غير مرفوع إلى Git، بعد التحقق منه من الخادم. لا تفترض أن اسم العرض وحده يحدد الهوية.
4. أضف نسخة `SKILL.md` إلى مسار المهارات الذي يدعمه محررك وفق `editor-guides/`.
5. تأكد أن MCP الخاص بـ Zoho Sprints متصل، ثم اطلب من المساعد إجراء **قراءة تحقق فقط** قبل السماح بإنشاء أو تعديل أي شيء.
6. اختبر كل دور على بيانات غير حساسة، وتأكد من أن حساب MCP نفسه لا يمتلك صلاحيات أوسع من المطلوب.

## قاعدة مهمة

إذا لم توجد أداة MCP المطلوبة (مثل إنشاء Sprint أو إكماله أو البحث في العناصر)، لا تخترع اسم أداة ولا تدّعِ نجاح الإجراء. وضّح القيد واقترح خطوة يدوية أو اطلب تفعيل الأداة المناسبة.

## المحررات المشمولة

- Claude Code / Claude Desktop (حسب طريقة دعم المهارات وMCP في الإصدار المستخدم)
- OpenAI Codex
- ChatGPT مع MCP متصل أو مساحة عمل تدعم الأدوات
- Cursor
- Kiro
- OpenCode
- Antigravity / محررات أخرى تدعم ملفات تعليمات ومصادر MCP

قد تختلف مسارات التثبيت بين الإصدارات؛ استخدم دليل المحرر داخل الحزمة وتحقق من وثائقه الحالية عند التطبيق.


## إضافة جديدة: ربط Git المحلي بـ Zoho Sprints
تتضمن النسخة المعززة سير عمل لتحليل الـ commits والـ diff والتعديلات غير المحفوظة، وربطها بقصص المستخدم والمهام، مع سجل محلي لمنع التكرار والاستكمال من آخر checkpoint. كما تتضمن سير عمل للمشاريع التي تستخدم BMAD.

ابدأ بقراءة:
- `workflows/git-change-audit.md`
- `workflows/git-change-ledger.md`
- `workflows/bmad-to-zoho.md`
- `prompts/AR_git_change_audit.md`
- `templates/zoho-git-audit-config.example.yaml`

التشغيل الافتراضي هو المراجعة دون كتابة (dry-run). يلزم تأكيد المستخدم قبل إنشاء العناصر ما لم يكن قد فوّض ذلك صراحة. صلاحيات Zoho والأدوات المتاحة هي التي تحكم التنفيذ الفعلي.
