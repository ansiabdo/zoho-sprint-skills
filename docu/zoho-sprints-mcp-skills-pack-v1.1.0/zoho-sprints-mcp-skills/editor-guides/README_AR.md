# تثبيت المهارة حسب المحرر

هذه الحزمة توفر مصدرًا واحدًا للسياسات (`skills/zoho-sprints/SKILL.md`) مع أمثلة لمسارات شائعة. قد تتغير المسارات حسب إصدار الأداة؛ إذا لم يتعرف المحرر على المسار، أضف محتوى `SKILL.md` إلى آلية التعليمات/المهارات المدعومة رسميًا لديه.

- **Claude Code**: ضع المهارة في مجلد `.claude/skills/zoho-sprints/SKILL.md` داخل المشروع، أو في مسار المهارات الشخصي الذي يدعمه إصدارك. إعداد MCP يتم منفصلًا.
- **Codex**: ضعها في `.agents/skills/zoho-sprints/SKILL.md` داخل المستودع، أو في مجلد المهارات الشخصي الذي يدعمه إصدار Codex. تأكد أن MCP متصل في بيئتك.
- **Cursor**: انسخ قواعد مختصرة إلى `.cursor/rules/zoho-sprints.mdc`، واحتفظ بالـ Skill الكاملة في المستودع. اربط MCP من إعدادات Cursor.
- **OpenCode**: استخدم `.opencode/skill/zoho-sprints/SKILL.md` إذا كان إصدارك يدعم مسار skills هذا؛ إعداد MCP مستقل.
- **Kiro**: انسخ قواعد المشروع الأساسية إلى `.kiro/steering/zoho-sprints.md`، وأضف المهارة إلى السياق/الملفات التي يقرأها الوكيل. إعداد MCP مستقل.
- **Antigravity**: إذا كان إصدارك يدعم Agent Skills، ضع المهارة في مسار المهارات المعتمد لديه؛ وإلا أضفها إلى تعليمات المشروع. تحقق من دعم MCP الفعلي.
- **ChatGPT**: عند استخدام MCP المتصل، أرفق `SKILL.md` ضمن تعليمات مساحة العمل/المشروع أو ابدأ المحادثة بطلب الالتزام بها. توافر MCP والكتابة يعتمد على المنتج والإعدادات والاتصال.
- **أي محرر آخر**: انسخ `SKILL.md` إلى ملف التعليمات الدائم الذي يدعمه، ثم اربط خادم MCP من إعداداته.

لا توجد طريقة واحدة تضمن التثبيت التلقائي في جميع المحررات؛ المهارة هي ملف تعليمات قابل للنقل، أما ربط MCP فيحتاج إعدادًا خاصًا بكل مضيف.
