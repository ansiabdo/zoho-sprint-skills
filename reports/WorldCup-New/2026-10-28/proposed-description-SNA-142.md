# Admin interface to manage tenant leagues

توثيق تتبع للعمل المسجل استنادًا إلى BMAD Story 10.4 وتغييرات واجهة الأدمن. لا يغير هذا التوثيق الأب الحالي أو حالة المهمة.

## نطاق العمل المرجعي والمرصود

- عرض catalog الدوريات والمواسم والخطة وحد المزود وحالة التفعيل في واجهة الأدمن.
- واجهة تعيين خطة المستأجر والدوريات المتاحة والتحقق من الخيارات غير الصالحة بعد تغيير الخطة.
- عرض تحذير downgrade عند إزالة دوريات لها تنبؤات، مع الإلغاء أوالمتابعة وفق الصلاحيات.
- حفظ إعدادات المستأجر عبر API والتعامل مع النجاح والخطأ والترجمة العربية/الإنجليزية وRTL.

## معايير التحقق المرجعية

1. لا تظهر دوريات خارج خيارات الخطة المعتمدة في نموذج التعيين.
2. تحديث الخطة يراجع الاختيارات ويعرض أثر الإزالة قبل الحفظ عند وجود تنبؤات.
3. المستخدم غير المخول لا يستطيع تنفيذ الحفظ.
4. توضح الواجهة معنى الاختيار الفارغ حسب عقد المنتج المعتمد.

## تعارض يحتاج قرار منتج

BMAD الحالي يستخدم القائمة الفارغة بمعنى default-all. القصة الأوسع SNA-127 تميز Selected الفارغة عن AllEntitled. لا يدعي هذا التوثيق أن السلوكين متطابقان أو أن جميع معايير SNA-127 منفذة، ولا يغيرهما.
