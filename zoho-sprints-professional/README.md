# Zoho Sprints Professional Skills

One canonical Codex skill with operation-specific workflows, read/write checks, a local audit ledger contract, and a generated portable distribution. See [Arabic guide](README_AR.md) and [requirements map](docs/REQUIREMENTS-TRACEABILITY_AR.md).

Requires Node.js 22+. Run `npm run check` before installing. Use `node tools/install.mjs --editor codex --target <project>` for a first install; add `--force` only after reviewing an existing installation. MCP authentication and the project-local role profile are configured separately. The package contains no private MCP endpoint or OAuth credentials.
