# مقارنة النسخ وتحليل الفجوات

| النسخة المرجعية | الحجم البنيوي وقت المراجعة | الفرق |
|---|---|---|
| الأصلية | 30 ملفًا | إرشادات أساسية لإدارة Zoho وأدوار المستخدمين |
| v1.1.0 | 38 ملفًا | إضافة Git audit وledger وBMAD؛ manifest القديم بقي على 30 |
| v1.2.0 | 19 ملفًا | اختصار نقطة الدخول وتجميع المراجع وإضافة مثبت واختبارات |
| الاحترافية v2.0.0 | مصدر ونسخة توزيع متطابقان | workflows وchecks منفصلة، عقد سلوك وJSON، قوالب، تثبيت متعدد المحررات وتتبع المتطلبات |

الفجوات المعالجة: توحيد المصدر والتوزيع، فحص روابط الملفات، اكتشاف الأدوات الحية بدل أسماء متخيلة، تقاطع حالة Sprint مع نافذتها الزمنية، الحفاظ على سجل تغييرات Git غير الملتزم بها منفصلاً عن HEAD، تعليق الإنشاء الملتبس بدل تكراره، مراجعة الحالات المسجلة أولاً، التتبع إلى مخرجات BMAD، وإضافة مسار إسناد المطور إلى قصة موجودة مع حفظ بقية المسند إليهم.

الفجوات التي تحتاج بيئة تشغيل: اختبار كل محرر فعليًا، تحديد هوية ودور المستخدم ومشروعه، واختبار دورة الإنشاء والتحقق على مشروع مصرح به. لا تعني اختبارات الملفات إتمام هذه الاختبارات الحية.

التفاصيل: [تتبع المتطلبات](REQUIREMENTS-TRACEABILITY_AR.md)، [تقرير الإصدار](../RELEASE-REPORT.md).
