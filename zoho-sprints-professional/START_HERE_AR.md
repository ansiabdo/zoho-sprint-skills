# ابدأ هنا

لخطوات الاتصال والتثبيت وتحديد المشروع مع أمثلة جاهزة، اقرأ [دليل البدء وربط MCP](GETTING_STARTED_MCP_AR.md).

هذه حزمة ملفات جاهزة للنقل، بدون ZIP. المهارة في skills/zoho-sprints تشمل دورَي الأدمن والمطور، workflows وchecks وقوالب الملفات المحلية.

1. اقرأ README_AR.md ثم editor-guides/README_AR.md.
2. ثبّت المهارة في مشروعك باستخدام tools/install.mjs أو انسخ مجلد المهارة كاملاً إلى مسار Skills المناسب.
3. اربط MCP في المحرر وحدد الدور والهوية في ملف profile المحلي.
4. ابدأ بفحص الاتصال، ثم نفذ طلبك. السجل ينشئه الوكيل عند تشغيل التدقيق داخل مشروعك؛ هذه الحزمة ليست خدمة مزامنة تعمل تلقائيًا.

الأدمن: إدارة المشاريع والسبرنتات والعناصر حسب أدوات MCP وصلاحيات الحساب.
المطور: استعراض المسند إليه، إضافة Task/Bug تحت قصة مسندة إليه، وإنشاء Story في Sprint نشطة ضمن تاريخها بعد فحص التكرار. الانضمام لقصة قائمة يتطلب صلاحية فعلية ويحافظ على المسند إليهم الحاليين.
Git: مراجعة السجل وحالات العناصر، ثم تحليل الفروقات التالية وربطها بالقصص وتسجيل نتائج الإضافة. BMAD: استيراد المخرجات المعتمدة مع تتبع المصدر ومنع التكرار.

لا تحتوي الحزمة على بيانات اتصالك الخاصة. لا تمنح تعليمات المهارة صلاحيات تتجاوز Zoho.
